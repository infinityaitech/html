CLASS 1 · THE FIRST WEB PAGE

Start with a sound structure.

HTML is the language that labels the parts of a web page. It tells the browser what the content is—not how it should look.

The document skeleton

Every page starts with a doctype, a root html element, page information in head, and visible content in body.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Page</title>
  </head>
  <body>
    <h1>My First Heading</h1>
    <p>My first paragraph.</p>
  </body>
</html>
  • <!DOCTYPE html> declares an HTML5 document.
  • head holds page information; title names the browser tab.
  • body holds the content visitors see.
  • UTF-8 supports characters in many languages, including Amharic.

Elements, tags, and attributes

An element usually has a start tag, content, and an end tag. Attributes add information in the start tag.

<p class="intro">Hello, <strong>web</strong>!</p>
<!-- A note in the source; it is not shown on the page. -->
<img src="images/campus-art.svg" alt="Illustrated campus">

Elements must be nested in the right order: close the most recently opened element first. Images, line breaks, and metadata are void elements, so they do not have closing tags.

Check your work

  1. Save the file with an .html extension and open it in a browser.
  2. Use browser DevTools to inspect the element tree.
  3. Validate the page at validator.w3.org and fix reported errors.

REMEMBER

HTML gives content its structure.

CSS controls presentation and JavaScript adds behavior. They are separate technologies with different jobs.
