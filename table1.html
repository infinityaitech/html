TABLES · CLASS EXAMPLES

Put related data in rows and columns.

Use a table when the information is genuinely tabular. A caption and header cells help readers understand the relationships in the data.

A simple student table

The caption names the table, th marks a header, and td holds a data cell. The scope attribute clarifies which cells each header describes.

Keep the structure simple.

Use tables for data, not for page layout. Add a caption and meaningful row and column headers.
