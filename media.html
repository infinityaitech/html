CLASS 3 · IMAGES, MEDIA & LINKS

Connect pages. Describe images.

A link points to another destination; an image is a separate file the browser loads. Good paths and useful alternatives make both work for more people.

An image with a caption

<figure>
  <img src="images/campus-art.svg"
       alt="Illustration of a green campus building">
  <figcaption>A campus in the morning.</figcaption>
</figure>

Write concise alt text that communicates the useful information in the image. For a purely decorative image, use alt="".

Choose the right path

Common file paths
FromToPath
index.htmlabout.html in the same folderabout.html
index.htmllogo.png inside imagesimages/logo.png
pages/contact.htmllogo.png in the parent folder's images../images/logo.png
Any pageA page on another websitehttps://example.com/

A relative path starts from the current file. An absolute URL gives the full web address.

Links have different destinations

  • Another page: read the campus story.
  • A section on this page: jump to file paths.
  • An email address: email the campus desk.
  • An external resource: open the HTML validator.

Use link text that explains where the link goes. When opening a new tab with target="_blank", add rel="noopener noreferrer".

Video, audio, and embedded pages

These elements can include controls and a fallback message. The filenames below are examples; add your own media files before using them.

<video controls width="640">
  <source src="media/intro.mp4" type="video/mp4">
  Your browser does not support video.
</video>

<audio controls>
  <source src="media/song.mp3" type="audio/mpeg">
</audio>

<iframe src="https://www.youtube.com/embed/VIDEO_ID"
        title="Introduction to HTML"
        width="560" height="315"></iframe>

Give every iframe a descriptive title. Some sites prevent their pages from being embedded.

Where is the file?

Count folders from the HTML file you are editing. Use ../ to move up one folder, then name the next folder and file.
